## OVERVIEW

Vike SSR framework + Vue 3 Composition API + Effector state management. Full-stack TypeScript app with Telefunc for server calls.

## STRUCTURE

```
vike-vue-effector/
├── pages/          # Vike page routes (+Page.vue, +config.ts)
├── components/     # Reusable Vue components
├── layouts/        # Page layout wrappers (LayoutDefault.vue)
├── utils/effector/ # Effector helpers (useUnit, scope management)
├── services/app/   # Global app state service
├── server/         # Express entry + handlers (telefunc, vike)
└── assets/styles/  # Global styles
```

## WHERE TO LOOK

| Task           | Location                        | Notes                    |
| -------------- | ------------------------------- | ------------------------ |
| Add page route | `pages/<name>/+Page.vue`        | Vike auto-routes by path |

| App entry      | `server/entry.ts`               | Express middleware setup |

## CONVENTIONS

**File Naming (Vike-specific):**

- `+Page.vue` — Page component (required)
- `+config.ts` — Page configuration (optional but used here)
- `+onPageTransitionStart.ts`, `+onPageTransitionEnd.ts` — Animation hooks
- `<name>/model.ts` — Per-page Effector state

**Effector Patterns:**

- `utils/effector/useUnit()` — Bind stores/events to components with scope awareness
- `Provider` in `LayoutDefault.vue` — App-wide scope provider
- Split `$counterServer` (SSR) vs `$counterClient` (hydration-safe) stores

**Path Aliases (tsconfig.json):**

```
@/*              → ./*
@utils/*         → ./utils/*
@services/*      → ./services/*
@layouts/*       → ./layouts/*
@components/*    → ./components/*
```

## ANTI-PATTERNS (THIS PROJECT)

- **DO NOT** create standalone store files outside `services/` or page models
- **NEVER** use `store.getState()` on client — always `useUnit()` for reactivity
- **DON'T** modify `dist/` — generated by build
- **AVOID** direct Effector imports in Vue components — prefer `@utils/effector`

## UNIQUE STYLES

- Telefunc integrated at `/api/_data` for server function calls
- Periodic prerender runs every 60s in production (`server/handlers/prerender.ts`)
- SSR + client hydration sync via scope merge patterns
